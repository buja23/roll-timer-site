# Roll Timer — Site oficial

Site de página única para apresentar o **Roll Timer**, aplicativo Android de temporização para aulas de jiu-jitsu.

🌐 **Site publicado:** https://roll-timer.jooj-soares-227.chatgpt.site

📲 **Download do Android (v1.0.0):** https://github.com/buja23/roll-timer/releases/download/v1.0.0/Roll-Timer.apk

## Sobre

- Descrição do aplicativo e botão de download direto da APK.
- Layout responsivo nas cores preto, vermelho e branco.
- Links para o código-fonte do app e para o desenvolvedor.
- QR Code para compartilhar a página.

## Como executar

O site é estático e não precisa instalar dependências. Abra `index.html` em um navegador ou execute um servidor HTTP na pasta do projeto, por exemplo:

```bash
python -m http.server 8000
```

Acesse `http://localhost:8000`.
